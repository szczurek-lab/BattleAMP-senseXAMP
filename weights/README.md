BattleAMP benchmark
---

In order to use SenseXAMP as part of BattleAMP benchmark, you have to download model checkpoints and put them in corresponding subdirectories.


|        Model         |                                             Checkpoint                                             | Subdirectory name |
|:--------------------:|:--------------------------------------------------------------------------------------------------:|-------------------|
|      Classifier      | [sensexamp_cls_balanced](https://drive.google.com/drive/folders/1JKNH-3gUD2qVkhWiUqXNF1Ef-a4CPzvS) | amp_cls           |
|  Regression E. coli  |  [sensexamp_reg_ecoli](https://drive.google.com/drive/folders/1QWrv0P2mo85AazilU7bzQrf8rWHM0lt-)   | amp_reg           |
| Regression S. aureus | [sensexamp_reg_saureus](https://drive.google.com/drive/folders/1QWrv0P2mo85AazilU7bzQrf8rWHM0lt-)  | amp_reg           |
